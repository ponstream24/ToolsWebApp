# WebTools

WebToolsは、日常的に必要となる様々なツールをウェブブラウザから簡単に利用できるようにしたサービスです。セキュリティ、データ変換、コード生成など、様々なカテゴリのツールを提供しています。

## 現在実装済みのツール

1. **QRコードジェネレーター**
   - 機能: テキストやURLからQRコードを生成
   - 説明: テキスト、URL、電話番号、Wi-Fi設定、メールアドレス、位置情報などからQRコードを生成できます。サイズ、マージン、エラー訂正レベル、色なども調整可能です。

2. **TOTPジェネレーター**
   - 機能: 2段階認証用のTOTPを生成
   - 説明: 時間ベースのワンタイムパスワード（TOTP）を生成し、Google AuthenticatorやMicrosoft Authenticatorなどの認証アプリと連携できます。既存のシークレットキーからTOTPコードを生成することも可能です。

## 追加すべきツール

1. **パスワードジェネレーター**
   - 機能: 安全なランダムパスワードを生成
   - 説明: 長さ、大文字・小文字・数字・記号の使用有無を指定して、安全なランダムパスワードを生成します。パスワードの強度も表示され、生成したパスワードをコピーして使用できます。

2. **テキストエンコーダー/デコーダー**
   - 機能: テキストの各種エンコード・デコード
   - 説明: Base64、URL、HTML、JSONなど、様々な形式でテキストをエンコード・デコードできます。プログラミングやウェブ開発で頻繁に必要となる変換を簡単に行えます。

3. **カラーピッカー**
   - 機能: 色の選択と変換
   - 説明: RGB、HEX、HSL、CMYKなど様々な形式で色を選択・変換できます。カラーパレットの作成や、選択した色の補色・類似色も表示します。

4. **単位変換ツール**
   - 機能: 様々な単位間の変換
   - 説明: 長さ、重さ、体積、温度、時間、データサイズなど、様々なカテゴリの単位を相互に変換できます。科学的な計算や日常生活で役立ちます。

5. **JSONフォーマッター/バリデーター**
   - 機能: JSONデータの整形と検証
   - 説明: 整形されていないJSONデータを読みやすく整形し、構文エラーを検出します。JSONデータの圧縮や、JSONからXMLへの変換なども可能です。

6. **マークダウンエディター**
   - 機能: マークダウン形式のテキスト編集とプレビュー
   - 説明: マークダウン記法でテキストを編集し、リアルタイムでプレビューを確認できます。編集したマークダウンをHTMLとしてエクスポートすることも可能です。

7. **画像圧縮ツール**
   - 機能: 画像ファイルの圧縮
   - 説明: JPG、PNG、GIF、SVGなどの画像ファイルを、品質をなるべく維持しながら圧縮します。ウェブサイトのパフォーマンス向上に役立ちます。

8. **URLショートナー**
   - 機能: 長いURLを短縮
   - 説明: 長いURLを短く、共有しやすい形式に変換します。短縮したURLのクリック数などの統計情報も表示できます。

9. **ハッシュ計算ツール**
   - 機能: テキストやファイルのハッシュ値を計算
   - 説明: MD5、SHA-1、SHA-256、SHA-512などの様々なアルゴリズムでテキストやファイルのハッシュ値を計算します。ファイルの整合性確認などに利用できます。

10. **正規表現テスター**
    - 機能: 正規表現のテストと検証
    - 説明: 正規表現パターンをテストし、マッチする文字列を確認できます。一般的な正規表現パターンのサンプルも提供し、正規表現の学習にも役立ちます。

## インストール方法

1. リポジトリをクローン
   ```
   git clone https://github.com/yourusername/ToolsWebApp.git
   ```

2. 依存関係をインストール
   ```
   composer install
   ```

3. 設定ファイルを編集
   ```
   cp config/app.example.php config/app.php
   # 必要に応じて設定を編集
   ```

4. ウェブサーバーを設定
   - DocumentRootを`/path/to/ToolsWebApp/public`に設定
